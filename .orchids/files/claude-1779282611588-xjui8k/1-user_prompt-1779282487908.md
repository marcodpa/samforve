PROMPT: Sitio Web Corporativo SAMFOR — Tema Claro
Construye un sitio web corporativo completo para SAMFOR, S.A. — empresa venezolana con 59 años de trayectoria en la industria petrolera, petroquímica, carbonífera y construcción industrial. El sitio debe proyectar autoridad, escala y confiabilidad al nivel de los grandes contratistas internacionales del sector energético.

DIRECCIÓN ESTÉTICA
Tono: Corporate Precision — limpio, poderoso, confiable. La elegancia del blanco industrial con acentos de color institucional. Piensa en Bechtel, Petrofac, o SLB en su versión web moderna: blanco dominante, tipografía fuerte, acento de color estratégico.
Paleta de color:

Fondo principal: #FFFFFF
Fondo secundario/secciones alternas: #F4F6F9
Fondo de cards: #FFFFFF con sombra 0 2px 16px rgba(0,0,0,0.07)
Acento primario: #C8102E (rojo SAMFOR)
Acento secundario: #1A6FB5 (azul SAMFOR)
Texto principal: #0D1117
Texto secundario: #4A5568
Líneas/divisores: #E2E8F0
Navbar fondo scroll: rgba(255,255,255,0.97) con backdrop-blur y sombra sutil

Tipografía:

Display/Títulos: Bebas Neue — fuerza industrial, condensada
Subtítulos/Nav: Barlow Condensed SemiBold
Cuerpo: DM Sans — legible, moderno
Datos/Labels técnicos: JetBrains Mono para números, años, métricas

Estilo visual:

Fondo blanco puro con secciones alternas en gris muy claro #F4F6F9
Cards blancas con sombra suave y borde izquierdo rojo al hover
Elementos decorativos: líneas diagonales rojas finas (guiño al logo SAMFOR)
Números de estadísticas con counter animation al entrar en viewport
Animaciones de entrada: staggered fade-up en secciones al hacer scroll
Imágenes industriales con overlay rojo muy sutil al hover
Separadores de sección con línea roja de 3px
Botones primarios: fondo rojo #C8102E texto blanco
Botones secundarios: outline azul #1A6FB5 texto azul

NO usar: fondos oscuros, gradientes púrpura, Inter/Roboto, diseño tipo startup SaaS, esquinas excesivamente redondeadas.

 Usa Tailwind CSS para utilidades base y CSS custom properties para el sistema de diseño.

REQUISITOS TÉCNICOS

Stack: React JSX single file, Tailwind CSS + <style> tag con CSS custom properties
Fonts: Google Fonts @import: Bebas Neue, Barlow Condensed, DM Sans, JetBrains Mono
Iconos: lucide-react
Estado: useState para navegación, filtros, formularios
Animaciones: CSS @keyframes + IntersectionObserver para scroll triggers y counter animation
Responsive: mobile-first, breakpoints 768px y 1024px
Accesibilidad: aria-labels, contraste mínimo 4.5:1, focus rings visibles en rojo
Sin localStorage/sessionStorage
